# M0.4 — Python/C++ boundary: hello event round-trip

- **Issue:** #4
- **PR:** #52
- **Milestone:** M0 — Repo, toolchain & boundary

## What I did

1. **The context:** M0.2 proved C++ can build, and M0.3 proved Python can install, lint, format,
   and test. M0.4 connects the two with the smallest useful cross-language call.
2. **Added a C++ hello-event boundary surface.** `chronos::round_trip_hello_event()` accepts a
   payload and returns a compact, versioned acknowledgement string:
   `chronos.boundary.v0|hello_ack|<payload>`.
3. **Added a C ABI shared library, `chronos_boundary`.** The exported function uses raw byte
   buffers plus explicit lengths and status codes. That keeps Python objects and C++ runtime
   types out of the boundary, matching ADR-0001.
4. **Added a Python `ctypes` wrapper.** `chronos.round_trip_hello_event("hello event")` loads the
   built shared library from `build/core/` and calls the native C ABI.
5. **Added tests on both sides.** C++ tests cover the native function and C ABI buffer behavior;
   Python tests prove a hello event travels from Python into C++ and back.
6. **Updated the aggregate gates.** `make python-check` now builds the native library before
   running pytest, Ruff lint, and Ruff format-check. `make cpp-check` runs the C++ build and
   CTest. `make m0-check` runs both.

## How to test and confirm

The retrospective hardening bounds hello-event payloads to 4096 UTF-8 bytes, maps native
failures to C status codes, hides C++ implementation symbols, and expands conformance tests for
empty, Unicode, embedded-null, exact-capacity, null-pointer, and limit cases.

7. **Sync the locked Python tooling:**
   `uv sync --group dev`.
8. **Run the full M0 gate:**
   `make m0-check`.
   Success means CMake configures, C++ builds, CTest passes, pytest passes, Ruff lint passes, and
   Ruff confirms formatting.
9. **Run the Python-to-C++ round-trip directly:**
   `uv run --group dev python -c 'import chronos; print(chronos.round_trip_hello_event("hello event"))'`.
   Success prints `chronos.boundary.v0|hello_ack|hello event`.
10. **What "success" means:** Python can invoke the C++ core through an explicit native boundary
    and receive a deterministic, versioned hello-event response. This is still scaffold code; real
    canonical contracts arrive in M1.
