# M0.6 One-Command Bootstrap + Docs

M0.6 adds a documented bootstrap command for a clean supported development machine.

The main command is:

```sh
make bootstrap
```

It verifies required host tools, syncs locked Python dev dependencies, configures and builds the
C++ targets, runs CTest, runs Python tests/lint/format checks, and executes the M0.4 Python to C++
hello-event round trip.

For a narrower manual check after bootstrapping:

```sh
make m0-round-trip
```
