# M0.6 One-Command Bootstrap + Docs

M0.6 adds a documented bootstrap command for a clean supported development machine.

The main command is:

```sh
make bootstrap
```

It validates required host tools and minimum versions, syncs locked Python dev dependencies,
runs the canonical `make m0-check` gate, and executes the M0.4 Python-to-C++ hello-event round
trip. `BUILDING.md` defines the supported macOS 15/AppleClang 16 and Ubuntu 24.04/Clang 18
machine envelopes with installation and checkout steps.

For a narrower manual check after bootstrapping:

```sh
make m0-round-trip
```
