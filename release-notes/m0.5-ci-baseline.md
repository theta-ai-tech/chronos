# M0.5 CI Baseline + Gate-Failure Proof

M0.5 adds the first GitHub Actions workflow for the mixed C++ and Python M0 scaffold.

The workflow runs on pull requests and pushes to `master`:

- installs pinned-enough CMake, Ninja, Python, and `uv`;
- syncs the locked Python dev tools;
- runs `make m0-check` for the positive build, lint, format, and unit-test gates;
- runs each `make m0-gate-proof PROOF=<name>` scenario as an independent CI matrix job.

The proof harness copies the repository into temporary directories, injects one focused
violation per gate, and treats an unexpected pass or mismatched failure signature as a failure.
Every mutation now runs through the real `make m0-check` CI aggregate, proving both the leaf
gate and its connection to CI. The matrix covers C++ warning-as-error, C++ unit tests, C++
clang-format, Python unit tests, Ruff lint, and Ruff format.
