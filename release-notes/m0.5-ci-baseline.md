# M0.5 CI Baseline + Gate-Failure Proof

M0.5 adds the first GitHub Actions workflow for the mixed C++ and Python M0 scaffold.

The workflow runs on pull requests and pushes to `master`:

- installs pinned-enough CMake, Ninja, Python, and `uv`;
- syncs the locked Python dev tools;
- runs `make m0-check` for the positive build, lint, format, and unit-test gates;
- runs `make m0-gate-proof` to show representative violations fail the expected gates.

The proof harness copies the repository into temporary directories, injects one focused
violation per gate, and treats an unexpected pass as a failure. It currently proves:

- C++ warning-as-error enforcement through `make cpp-build`;
- C++ unit-test enforcement through `make cpp-test`;
- Python unit-test enforcement through `make python-test`;
- Python Ruff lint enforcement through `make python-lint`;
- Python Ruff format enforcement through `make python-format`.
